# Documentacion del proyecto

Punto de entrada rapido a la documentacion del repo.

## Mapa

1. `01-contexto-proyecto.md` - objetivo, alcance y filosofia del producto.
2. `02-flujo-usuario.md` - recorrido principal del usuario por la app.
3. `03-plan-pwa-offline.md` - plan tecnico para PWA y modo offline.
4. `04-er.md` - modelo entidad/relacion y contratos de dominio.
5. `05-mockups-ascii.md` - bocetos de las pantallas principales.
6. `06-seguridad.md` - checklist de hardening y seguridad.
7. `07-checklist-deploy.md` - validaciones antes de exponer el servicio.
8. `08-arquitectura-frontend.md` - estructura real del frontend Angular.
9. `09-componentes-compartidos.md` - shared, pipes, toasts y dialogs.
10. `10-testing.md` - estrategia minima de pruebas y cobertura.

## Recomendacion de lectura

1. Empieza por `01`, `02` y `04` para entender producto y dominio.
2. Sigue con `08` y `09` para entender la implementacion real.
3. Usa `10` cuando quieras ampliar tests o validar cambios.
