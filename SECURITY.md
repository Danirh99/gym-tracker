# Security Policy

## Supported versions

Este proyecto esta en etapa temprana. La rama soportada para parches de
seguridad es:

- `main`

## Reporting a vulnerability

Si encuentras una vulnerabilidad, por favor no abras un issue publico.

En su lugar, reportala de forma privada por email:

- danielruizherrera.dev@gmail.com

Incluye, si es posible:

- Descripcion del problema
- Pasos para reproducir
- Impacto potencial
- Version/rama afectada
- Propuesta de mitigacion (opcional)

### Que esperar

- Confirmacion de recepcion en 72 horas.
- Evaluacion inicial y plan de accion.
- Coordinacion para disclosure responsable.

Gracias por ayudar a mantener Gym Tracker seguro.
